מה תוקן כדי להתאים לדף ההוראות של פרויקט 6

1. נוספו נתיבי REST בסגנון jsonplaceholder:
   users = travelers
   todos = trips
   posts = journal
   comments = memories

2. נתיבי השרת החדשים:
   GET/POST    /users/:userId/todos
   PUT/DELETE  /users/:userId/todos/:id
   GET/POST    /users/:userId/posts
   PUT/DELETE  /users/:userId/posts/:id
   GET/POST    /posts/:entryId/comments
   PUT/DELETE  /posts/:entryId/comments/:id

3. הנתיבים הישנים נשארו כדי לא לשבור את TripDiary:
   /travelers/:userId/trips
   /travelers/:userId/journal
   /journal/:entryId/memories

4. הלקוח React עודכן להשתמש בנתיבים החדשים, כך שב-Network יראו:
   /users/.../todos
   /users/.../posts
   /posts/.../comments

5. ב-Todos נוסף checkbox:
   checked = status completed
   unchecked = status planned

6. נוספו proxy rules ב-vite.config.js עבור:
   /users
   /posts

7. נבדק:
   client npm run build עבר בהצלחה.
   server node --check עבר על כל קבצי JS.

הסבר להצגה:
הפרויקט הוא TripDiary, אבל מבחינת REST הוא מקביל ל-jsonplaceholder:
trips הם todos, journal הם posts, memories הם comments.
