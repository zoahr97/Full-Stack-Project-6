# Full-Stack Project 6

**Academic grade: 95/100**

This project is a full-stack web application built with React, Node.js, Express, and MySQL. It implements a client-server architecture inspired by JSONPlaceholder, allowing authenticated users to manage their own data through a RESTful API.

The React client provides registration, login, logout, protected routes, and a user-friendly interface for viewing and managing todos, posts, and comments. Communication with the server is performed through asynchronous HTTP requests to Express API endpoints.

The backend is built with Node.js and Express and is connected to a MySQL database. It exposes REST API endpoints for CRUD operations and verifies that each user can access and modify only their own data. User authentication and authorization are handled through secure server-side validation.

## Key Features

- User registration and login
- User-specific protected data access
- React client with routing and reusable components
- RESTful API built with Node.js and Express
- MySQL database for users, passwords, todos, posts, and comments
- Full CRUD operations: create, read, update, and delete
- Todo management, including completion status
- Post management with related comments
- Permission validation for updating and deleting user-owned content
- API testing using Postman

## Technologies

**Frontend:** React, React Router, JavaScript, CSS, Fetch / Axios  
**Backend:** Node.js, Express  
**Database:** MySQL  
**API:** RESTful API  
**Tools:** Postman, Git, GitHub
